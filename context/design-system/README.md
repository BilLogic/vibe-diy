# SDS Design System

The Simple Design System (SDS) is a complete component library built by Figma, following Material Design 3 principles ([m3.material.io](https://m3.material.io/)).

## Structure

| Folder | What it covers |
|--------|---------------|
| `foundations/` | Design principles, accessibility standards, layout system |
| `styles/` | Color, typography, elevation, shape, motion, iconography tokens |
| `components/` | Master index of all available components |

## Upstream

- Source repo: [figma/sds](https://github.com/figma/sds)
- Figma file: [Simple Design System](https://www.figma.com/community/file/1380235722331273046/simple-design-system)
- Storybook: https://figma.github.io/sds/storybook

## Source of Truth

- Component code: `src/ui/primitives/`, `src/ui/compositions/`, `src/ui/layout/`
- Token definitions: `src/theme.css`
- The docs in this folder are curated summaries for agent consumption — always defer to the source code when in doubt.
