# Design Principles

Five principles guide every design decision in SDS.

## 1. Clarity Over Decoration

Every element should serve a purpose. Remove what doesn't communicate. Prefer whitespace and typography over decorative graphics.

## 2. Consistency Builds Trust

Use the same components, tokens, and patterns everywhere. Users learn the system once and navigate confidently. Never invent a custom component when SDS provides one.

## 3. Accessible by Default

Design for everyone from the start — not as an afterthought. Meet WCAG 2.1 AA standards. See `accessibility.md` for specific requirements.

## 4. Content-First Hierarchy

Structure layouts around the content, not around visual decoration. Typography scale and spacing tokens create hierarchy. Let the content lead.

## 5. Progressive Disclosure

Show what's needed now, reveal details on demand. Use Accordion for collapsible content, Dialog for focused decisions, Tooltip for supplementary info. Don't overwhelm with everything at once.
