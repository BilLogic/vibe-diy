## Interactive before/after on the landing page

**Context:** The landing page needs to communicate what compound designing actually does. A text description works, but a visual comparison would be more compelling.

**Idea:** Show a side-by-side of designing with vs. without a compound designing system. The "without" side shows scattered, inconsistent output. The "with" side shows cohesive, system-driven output that improves over iterations.

**Potential:** Could use SDS Grid + Cards for the comparison layout. Two columns, each containing a card with a representative screenshot or code snippet. Simple to build with existing components, high impact for communicating the core concept.

**Status:** Proposed
