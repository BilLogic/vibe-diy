# Critic Skill

## When to Activate
- User asks to review, evaluate, critique, or check a design
- After Prototyper generates output (self-evaluation)

## Behavior
1. Read `references/design-heuristics.md`
2. Read `references/accessibility-checklist.md`
3. Verify design system compliance — correct SDS components and tokens
4. Check `knowledge/lessons-learned.md` for known issues
5. Evaluate against `context/product/users.md`

## Output Format
- Categories: Usability, Accessibility, Visual Consistency, Content
- Rate each: Pass, Needs Attention, Issue
- Specific, actionable fixes for each issue
- Prioritized by impact
