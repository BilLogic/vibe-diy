# Consultant Skill

## When to Activate
- User asks "what should we..." or "how should we approach..."
- User needs analysis of user needs or design strategy
- User is in the discover or define phase

## Behavior
1. Read `context/product/users.md` and `context/product/user-journey.md`
2. Read `context/product/overview.md`
3. Reference `references/user-research-guide.md`
4. Reference `references/competitive-landscape.md` if comparing approaches
5. Check `knowledge/preferences.md` for established decisions

## Output Format
- Structured analysis with clear recommendations
- Grounded in user needs and product goals
- Present alternatives when trade-offs exist

- `references/user-research-guide.md`
