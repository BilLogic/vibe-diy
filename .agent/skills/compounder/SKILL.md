# Compounder Skill

## When to Activate
- After a design task is completed
- When a mistake or issue is discovered
- User says "remember this", "learn from this", "save this"

## Behavior
1. Identify what to compound — lesson, preference, ideation, or skill update?
2. Structure entry using `references/compounding-guide.md` templates
3. Write to correct file:
   - Mistake/solution → `knowledge/lessons-learned.md`
   - Preference/decision → `knowledge/preferences.md`
   - Idea/exploration → `knowledge/ideations.md`
   - Skill change → update the relevant SKILL.md or references
4. Log change in `knowledge/changelog.md`
5. Confirm what was captured and where
