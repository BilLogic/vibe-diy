# Explore Prompts

Open-ended prompts for experimentation. Try these after the landing page demo to push the system further.

---

## 1. Redesign the hero section

> Redesign the hero section of the landing page. Show me 3 different approaches -- one typographic, one with a visual metaphor, one minimal. Use SDS components and tokens for all three.

## 2. Add a "What is Compound Designing?" explanation section

> Add a section to the landing page that explains what compound designing is. Keep it concise -- no more than 3 short paragraphs. Use a layout that breaks up the text visually.

## 3. Add a schedule/timeline section with detailed breakdown

> Add a schedule section to the landing page with a detailed breakdown of the 60-minute workshop. Include time blocks, topics, and format (talk vs. hands-on). Use SDS components for the layout.

## 4. Test individual skills: Consultant to Prototyper handoff

> Ask the Consultant for a strategy recommendation about the landing page structure, then hand off the result to the Prototyper to build it. Observe how context flows between skills.

## 5. Build your own skill

> Create a 5th skill in `.agent/skills/`. Define its role, when it activates, and what it references. Test it by invoking it with a relevant prompt.

## 6. Compare with vs. without context

> Try the landing page prompt in a fresh repo that has no `context/` directory. Compare the output to what the compound system produces. Note the differences in component usage, token adherence, and design consistency.

## 7. Adapt to your own project

> Swap the product context in `context/` for your own project. Replace the persona, product brief, and design system references with your own. Then run the landing page prompt again and see how the output changes.
