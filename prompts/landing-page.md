# Landing Page Prompt

This is the main demo prompt for the compound designing system. Paste it into your AI tool and observe how the agent uses context, knowledge, and skills to produce the design.

## The prompt

> Design a landing page for a workshop called "Compound Designing" at Carnegie Mellon University. The workshop is a 60-minute session for design students about building AI-powered design systems that improve over time. The speaker is Bill Guo, BHCI grad, UXA alum, and Design Lead at PLUS. Include: hero section with title + subtitle + hook, description of compound designing, speaker info, what attendees will learn (3-4 outcomes), format and logistics (30 min talk + 30 min hands-on), registration CTA. Make it responsive, accessible, and true to the design system.

## What to look for

Use this checklist to evaluate how well the agent uses the compound designing system:

- [ ] Agent reads persona and product context before starting
- [ ] Agent checks lessons-learned before generating
- [ ] Agent uses SDS components (not custom HTML)
- [ ] Agent uses design tokens (not hardcoded values)
- [ ] Agent uses Flex/Section/Grid for layout
- [ ] Agent offers to compound lessons after completing
