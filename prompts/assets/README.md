# Workshop Demo Assets

Visual assets for the Compound Designing workshop presentation.

## Narrative Flow

### 1. The Problem (rage texts)

Screenshots showing what happens when AI agents work WITHOUT compound designing — frustrating, off-brand, and broken output.

| Asset | Shows |
|-------|-------|
| `rage-text-noooo.png` | "noooo" — agent ignoring style prompts |
| `rage-text-fix-css.png` | "it aint right" — agent apologizing for CSS mistakes |
| `rage-text-trash.png` | "trash" — agent outputs categorized as garbage |
| `rage-text-noooo-2.png` | More frustration with agent quality |
| `rage-text-noooo-3.png` | More frustration with agent quality |

### 2. The Comparison (prototype outputs)

Same design task executed by different tools — showing quality differences.

| Asset | Tool | Shows |
|-------|------|-------|
| `compare-plus-uno.png` | PLUS (compound designing) | Polished, on-brand, context-aware output |
| `compare-v0.png` | v0 | Generic AI prototype — functional but bland |
| `compare-figma-make.png` | Figma Make | Another generic output — different but still generic |

### 3. The Solution (PLUS compound system)

Screenshots of compound designing in practice at PLUS.

| Asset | Shows |
|-------|-------|
| `plus-uno-marketplace.png` | Prototype marketplace — 25 deployed prototypes with tags, fidelity levels, creators |
| `plus-uno-readme.png` | Repo README showing agent workflow, component counts, directory structure |

## Usage in Workshop

- **Talk portion (30 min):** Use rage texts to set up the problem, comparisons to show the gap, PLUS screenshots to show the solution
- **Hands-on portion (30 min):** Students replicate the compound designing approach using this repo
